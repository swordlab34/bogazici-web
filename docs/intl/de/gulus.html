Häufige Fragen

Ist es kostenpflichtig?

Nein, es ist völlig kostenlos. Sie sind danach nicht verpflichtet, zu uns zu kommen.

Sieht das Ergebnis wirklich so aus?

Die Vorschau soll Ihnen eine Vorstellung geben. Die passende Behandlung und das tatsächliche Ergebnis werden bei der Untersuchung mit Ihrem Zahnarzt festgelegt.

Was passiert mit meinem Foto?

Es wird nur für Ihre Vorschau verwendet. Wenn Sie den Code nicht innerhalb von 72 Stunden per WhatsApp senden, wird Ihr Foto gelöscht; andernfalls werden Foto und Vorschau nach 30 Tagen automatisch gelöscht.

Warum sende ich einen Code per WhatsApp?

Damit die Vorschau nur an den tatsächlichen Inhaber der Nummer geht. Der Code ist einmalig gültig und nur, wenn er von der im Formular angegebenen Nummer gesendet wird.
